# یه قرار دونفره

یک گردونه‌ی فارسی و موبایل‌پسند برای انتخاب قرار. بخش «رفتن به خرید» زیر نشانگر می‌ماند و هر بار که گردونه را بچرخانی، همان گزینه انتخاب می‌شود. دکمه‌ی «ارسال به عشقم» چت تلگرام `@Hamirasekh` را با پیام آماده باز می‌کند؛ برای ارسال نهایی باید دکمه‌ی ارسال تلگرام را بزنی.

## اجرا

- برای دیدن سایت، فایل `index.html` را در مرورگر باز کن.
- برای نصب‌کردن به شکل وب‌اپ و فعال‌شدن حالت آفلاین، سایت را با HTTPS میزبانی کن و از مرورگر موبایل گزینه‌ی Add to Home Screen / نصب را بزن.
- مخزن برای GitHub Pages آماده است؛ بعد از فعال‌شدن workflow، سایت از آدرس `https://nadiamohamdian.github.io/dating/` در دسترس خواهد بود.

این پروژه HTML، CSS و JavaScript ساده است و وابستگی نصب‌شدنی ندارد.
